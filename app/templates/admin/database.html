Sicherung erstellen

Erstellt eine Sicherheitskopie der aktuellen Datenbank in data\backup\. Diese Aktion ist jederzeit sicher.

Datenbank exportieren (für Abrechnung)

Lädt die komplette Datenbank als Datei herunter. Das ist der empfohlene Weg, um die Daten auf einen zweiten Rechner zu übertragen (z. B. Abrechnung).

Datenbank exportieren

Jahresarchiv erstellen

Erzeugt eine separate Archiv-Datei für ein Jahr (z. B. manifest_2025.db). Die aktive Datenbank bleibt dabei unverändert.

Datenbank laden (ersetzen)

Was bedeutet „Datenbank laden“?
Diese Funktion ersetzt die aktuelle Datei data\manifest.db durch die hochgeladene Datei. Das ist sinnvoll, wenn du auf diesem Rechner die Datenbank vom anderen Rechner übernehmen möchtest (z. B. für die Abrechnung).
Vor dem Ersetzen wird automatisch ein Backup erstellt und im Ordner data\backup\ abgelegt. {% if last_backup and last_backup.file %} Letzte Sicherung: {{ last_backup.file }} {% endif %}
Tipp: Wenn du unsicher bist, nutze zuerst „Datenbank exportieren“ auf dem anderen Rechner.
